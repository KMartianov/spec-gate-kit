# Фаза E — backlog с триггерами (после 0.2.0)

- **Дата:** 2026-10-03
- **Назначение:** зафиксировать, что сознательно **не** делается сейчас, с условиями пересмотра.
- **Основание:** решения `.slim/spec/notes/decisions-2026-10-02.md` (§D1/D3) + оценка `@oracle` (ora-6).

## DROP (не планируется; пересмотр только по триггеру)

| Тема | Почему drop | Триггер пересмотра |
|------|-------------|--------------------|
| Подписи `audit-chain` (HMAC / Ed25519 / GPG) | Writer и verifier — один uid/диск; ключ рядом с артефактом не даёт ничего против same-uid. Нужен off-disk ключ/железо/remote — а это уже другая архитектура. | Появление **off-machine verifier** (внешний потребитель должен проверять, не доверяя диску) **или** split writer/verifier по uid. Тогда — Ed25519 / `ssh-keygen -Y sign`, не HMAC. |
| Внешний якорь/шиппер (rekor/remote sink/WORM) | В hook запрещён (§1.3 `audit-chain-p0`): ломает автономность/offline, добавляет deadlock. | Требование независимого witness-сервиса. |
| m6 — дедупликация резолверов (`find_root`×7, `die`, `parse_dod`) | YAGNI: дублирование косметично; правки делать **попарно** с расширением векторов, не «рефакторинг ради рефакторинга». | Конкретный баг, вызванный расхождением копий. |
| m7 — удаление semi-dead кода (`hasValidApproval`, `pickPath`, пустой `after`-hook) | Compat/test-шимы; пустой `after` зарегистрирован и проверяется тестом (инвариант v2-parity). | Смена публичного тест-контракта. |
| Контент Diátaxis-квадрантов (`docs/{tutorials,how-to,reference,explanation}`) | 4 WARN при rc=0; `docs/**` — human-owned (GOV-2), заглушки = шум. | Первая реальная путаница adopter'а. |
| Потребление `scope_sha256` в формуле `passing` (`spec-status`) | Сменило бы семантику DONE (двухуровневая staleness = оптимизация расписания, **не** сертификация). | Явное решение о двухуровневой staleness. |
| N1 — `examples/minimal` как «copy-me» (не линтится на месте) | Пример — шаблон для копирования; `docs-lint` ищет `<path>/.slim/spec`. | Путаница adopter'а при попытке линтить пример in-place. |
| M9 — расхождение `findRoot` TS (cap 32, `p!==HOME`) ↔ Python (без cap, HOME гейтит) | Оба триггера патологичны ($HOME как корень проекта; вложенность >32). | Любой из этих двух сценариев. |
