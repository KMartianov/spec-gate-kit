---
description: Утвердить .slim/spec (человеческий Zero-Code Gate) и разблокировать правки кода
---

Инициировать утверждение может **только человек**. Агент не вправе создавать, подделывать или «самоутверждать» запись об утверждении, а также запускать `bin/spec-approve` иначе как через эту команду по просьбе человека.

Аргументы: `$ARGUMENTS`

!`~/.config/opencode/bin/spec-approve $ARGUMENTS`

Формы вызова:

- `/spec-approve` — без аргументов это **read-only обзор**: по одной строке на файл в `.slim/spec/` (`slug class token approval scope gate`). Ничего не пишет.
- `/spec-approve <slug>` — утвердить один контракт. Голый слаг работает: он разрешается как `<проект>/.slim/spec/<slug>.md`, затем `<slug>.md`, затем по цепочке родительских каталогов.
- `/spec-approve <путь/к/спеке.md>` — утвердить по пути; допустим и каталог (его `*.md`).
- `/spec-approve --all` — утвердить все активные контракты проекта одной командой (вместо ручного перебора слагов).
- `/spec-approve --changed` — то же, но пропустить спеки, у которых уже есть валидная запись.
- `--strict` — считать проблемы `scope`/`dod` отказом, а не предупреждением.
- `--restamp` — перезаписать строку `Утверждено` у уже утверждённой спеки. **ВНИМАНИЕ:** байты спеки меняются, поэтому всё `verify/*.json` по ней становится stale и состояние падает `DONE → VERIFY`. Обычно не нужен.

Отказы: `exit 2` — файл не контракт (index `roadmap`/`index`, `undeclared`), лежит в `archive/**` или вне `.slim/spec` — тогда ничего не записано. Спека без `scope`-фенса утверждается с предупреждением (`gate: allow … (scope grants nothing)`), потому что такой мандат ничего не разрешает.

Коды возврата: `0` — успех; `1` — ошибка ввода/разрешения или не подтвердился гейт; `2` — отказ (ничего не записано); `3` — частичный успех в `--all`/`--changed`.

Не изменяй файлы и не запускай другие инструменты. Ответь ОДНОЙ строкой: путь к записи об утверждении или текст ошибки. Если CLI не сработал, покажи список доступных слагов из текста ошибки и предложи человеку повторить с полным путём `<проект>/.slim/spec/<slug>.md`.
