# `examples/` — сквозные примеры

Минимальные самодостаточные примеры того, как выглядит рабочий контракт
`spec-gate-kit` и как проверить его **read-only** CLI кита.

| Пример | Что показывает |
|---|---|
| [`minimal/`](minimal/) | один контракт `example-task.md` с валидным `scope`-фенсом (машинный мандат записи) и `dod`-фенсом со slug-префиксными `id` |

## Чем эти примеры не являются

- Это **не** контракты самого кита: они лежат в `examples/**/spec/` (вне корневого
  `.slim/spec/`), имеют статус `draft` и никогда не одобряются человеком. Файл
  примера копируется принимающим проектом в `<project>/.slim/spec/`.
- Их `dod`-чеки не входят в Definition of Done кита и не исполняются
  `dod-run`/`wave-run`/CI.
- `examples/` — не `docs/`-квадрант и не связан с `docs-lint` кита; каталог
  `docs/**` — human-owned зона (GOV-2).

Проверки примера запускаются **из корня репозитория кита**: CLI резолвят пути
относительно себя (см. `minimal/README.md`).
