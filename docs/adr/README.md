## Как читать

- **Статус.** `proposed` — предложено, не действует; `accepted` — действует,
  реализацию нельзя менять, не заменив ADR; `superseded by ADR-XXXX` — заменено.
- **Связь со спецификациями.** Каждая задача ссылается на базовый ADR из
  `.slim/spec/<task_slug>.md`. Нормативный контракт живёт в спецификации,
  обоснование выбора — здесь.
- **Изменение решения.** Не редактируйте `accepted`-ADR. Заведите новый ADR со
  статусом `accepted` и в старом проставьте `superseded by ADR-XXXX`.
